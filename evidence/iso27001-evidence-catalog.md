## How to Use This Catalog

This catalog maps each ISO 27001:2022 clause and Annex A control to the evidence required to demonstrate conformance. Use it to:

1. **Pre-certification:** Identify evidence gaps before your Stage 1 or Stage 2 audit
2. **Internal audit:** Request evidence systematically using the catalog as an evidence request list
3. **Surveillance audits:** Confirm that evidence is current and controls remain operational

**Status Codes:**
- ✅ On file and current
- ⚠️ On file but needs update
- ❌ Not on file / gap identified
- N/A — Control excluded from SoA with documented justification
